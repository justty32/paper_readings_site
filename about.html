ABOUT THIS FIELD GUIDE

先懂問題，
再把論文讀深。

這是一份論文閱讀庫的入門導覽，給想先看懂研究在忙什麼的人。

每課只帶走一個核心

直覺與日常類比放在主線，流程圖拆解角色，互動讓你改一個條件。公式、方法差異與限制放在原生可摺疊區塊，鍵盤也能開啟。課程不是全庫逐篇摘要，也不取代閱讀論文。

來源怎麼看？

分類沿用 paper_readings 的 A–J 索引。既有概念課依已提交的摘要與精要逐節譯文編寫，未宣稱重新完整閱讀所有原始 PDF。新增的單篇論文導讀另外核對公開原文，逐篇列出自己的母稿版本、章節定位與來源；兩種閱讀入口的版本分開記錄。每課列出實際依據的筆記路徑與 arXiv 原文入口；正文的論文編號可跳到來源卡。

概念課快照固定於 1f91be9，日期 2026-11-05。來源庫日後新增論文，不會自動改變這版課程。單篇導讀使用各頁來源卡標示的獨立快照。來源中的逐節譯文仍是閱讀筆記，關鍵定義、數字與引用請回查原文。私人來源快照的 GitHub 追溯連結需要論文庫存取權；已公開的摘要／精要逐節譯文閱讀站可以直接閱讀。各論文導讀的「接著讀」列出對應公開入口；這些是閱讀筆記，並非官方全文翻譯。arXiv 原論文入口亦可公開閱讀。

圖和數字代表什麼？

所有 SVG、流程圖與互動是本站手製教學示意，使用合成資料或手寫規則；不是論文實驗圖，也沒有在瀏覽器訓練大型模型。旋鈕改變圖形，不代表模型已學會那些因子。未列出實驗數字時，刻意不以玩具結果推斷真實效能。

怎麼讀比較輕鬆？

  1. 讀標題底下的問題，再讀「先抓住這個直覺」。
  2. 對照圖中每一步的角色，改一次互動條件。
  3. 能說出方法做了什麼，再展開限制，挑一篇來源讀。

使用與隱私

網站無追蹤、無登入、無後端。閱讀勾選只存在瀏覽器的 localStorage；若停用儲存，文章與互動仍可閱讀。可以在閱讀地圖使用下方按鈕清除本站的勾選，其他網站資料不受影響。

維護方式

這是免依賴的靜態網站。內容保存在 JSON，Python 產生 HTML；手機、鍵盤、無 JavaScript 時仍能閱讀主線與來源。回閱讀地圖，挑一個現在最有趣的問題。
